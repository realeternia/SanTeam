# 王职业英雄技能设计（方案稿）

## 一、概述

王职业共 6 名英雄，当前 Skill1 均为占位"强"（未挂载个人技能），本次全部落地。技能 Id 段 **2021021~2021050**（6 人 × 5 级 = 30 行，已验证该段空闲）。

| 英雄 | heroId | 阵营 | 品质 | 费用 | 设计策略 | Id 段 |
|---|---|---|---|---|---|---|
| 刘备 | 100001 | 蜀 | 3 精良 | 6 | 精细（仁德） | 2021021~2021025 |
| 曹操 | 100002 | 魏 | 4 史诗 | 8 | 最精细（护驾/奸雄） | 2021026~2021030 |
| 孙权 | 100003 | 吴 | 3 精良 | 6 | 精细（制衡） | 2021031~2021035 |
| 董卓 | 100004 | 群 | 3 精良 | 6 | 简单粗暴（范围给 buff） | 2021036~2021040 |
| 司马炎 | 100005 | 晋 | 2 普通 | 4 | 简单粗暴（范围给 buff） | 2021041~2021045 |
| 袁绍 | 100006 | 群 | 2 普通 | 4 | 简单粗暴（范围给 buff） | 2021046~2021050 |

## 二、设计思路

参考三国杀/三国无双的君主技能主题，统一走"群体强化、属性挂钩"路线：

- **刘备·仁德**（三国杀【仁德】）：仁德施政——群体治疗 + 群体攻击强化。治疗量走 `GetSkillHeal()`（ap 属性挂钩），强化走新 Buff"仁政"（攻击提升）。
- **曹操·护驾**（三国杀【护驾】+【奸雄】）：护驾保人——群体护盾 + 自身吸血，攻守兼备，最高品质最高数值。
- **孙权·制衡**（三国杀【制衡】）：制衡之道——范围内友军**随机**获得一种强化（攻速/移速/伤害提升），体现制衡变通。
- **董卓·暴虐**：暴虐之威——范围内友军伤害提升（buff=重）。
- **司马炎·一统**：一统之势——范围内友军减伤（buff=硬）。
- **袁绍·名门**：四世三公——范围内友军持续回血（buff=愈）。

## 三、核心约定

- 全部为 **Aid 主动技能**（覆写 `CheckAidSkill`，`SkillManager.CheckAidSkill` 每帧轮询），`Rate=0` 必发、CD 到即放。
- 全部 `Type="术"`、`DamageType=0`（治疗统一法术向，ap 成长），Buff 机制不直接造伤害。
- Sname = 英雄名（刘备/曹操/孙权/董卓/司马炎/袁绍），与王职业技能"诸侯"（Sname="王"）不冲突。
- 描述全部用内联字段（`/strength`、`/strength2`、`/strengthint`、`/targetcount`、`/bufftime`）。
- 数值全部走 `SkillConfig` 行，不硬编码；Buff 的 Strength 取自**施放技能**的 skillCfg（Buff 基类构造 `skillCfg = SkillConfig.GetConfig(skillId)` 已保证）。
- 复用现有 Buff 池：盾 300001 / 吸 300003 / 重 300004 / 快 300005 / 愈 300007 / 硬 300002 / 翼 300010；仅刘备新增 1 个 Buff（仁政 300027）。
- 技能类内 `BuffConfig.GetConfigByNameS` 判空时记 `GameLog.Error`，禁止静默。

## 五、高品质 3 人详设（精细设计，各新增 1 个技能脚本）

### 刘备·仁德（2021021~2021025）— 新增 SkillAidBenevolence + Buff 仁政

> 仁德之政，为范围内最多/targetcount名友军英雄回复/strength生命，并附加仁政提升攻击/strength2点，持续/bufftime秒

- **治疗**：`GetSkillHeal()` = Strength × (100+ap)/100，**ap 属性挂钩**；只选友军英雄、跳过满血（满血不治疗仍附加仁政）
- **仁政**：新 Buff 300027（读技能 Strength2 加攻，与治疗量数值分离）
- CD 9 / MP 16 / Range 100 / TargetCount 3→3→3→4→4 / BuffTime 6→6→7→7→7
- Strength（治疗）40→60→80→100→120 / Strength2（攻）15→20→25→30→35

```csharp
config[2021021] = new SkillConfig(2021021, "仁德", "刘备", "仁德之政，为范围内最多/targetcount名友军英雄回复/strength生命，并附加仁政提升攻击/strength2点，持续/bufftime秒", "术", 1, 0f, 9f, 16, "", 0, "", 100f, 0f, "", 3, 40f, 15f, 0, "仁", false, 6f, "", 0, 0f, 0f, 0f, 0, "SkillAidBenevolence", "sway", "MagicChargeYellow", 0f, "liubei", "", "", "");
```

### 曹操·护驾（2021026~2021030）— 新增 SkillAidImperialGuard

> 护驾天下，为范围内最多/targetcount名友军英雄套/strength2%最大生命护盾；自身获得吸血/strength%，持续/bufftime秒

- **护盾**：Strength2 存盾% maxHp，技能类 `(buff as BuffShield).SetHp((int)(maxHp × Strength2))`（参照李严护军模板，走技能类直接设值，不依赖 Buff 数值槽）
- **吸血**：Strength 存吸血比例，BuffSuck 读 `skillCfg.Strength` ✓（`damage × Strength` 回复，不吃治疗加成）
- CD 10 / MP 18 / Range 80 / TargetCount 4→4→4→5→5 / BuffTime 6→6→7→7→8
- Strength（吸血）0.10→0.15→0.20→0.22→0.25 / Strength2（盾%）0.20→0.25→0.30→0.35→0.40

```csharp
config[2021026] = new SkillConfig(2021026, "护驾", "曹操", "护驾天下，为范围内最多/targetcount名友军英雄套/strength2%最大生命护盾；自身获得吸血/strength%，持续/bufftime秒", "术", 1, 0f, 10f, 18, "", 0, "", 80f, 0f, "", 4, 0.10f, 0.20f, 0, "吸", false, 6f, "", 0, 0f, 0f, 0f, 0, "SkillAidImperialGuard", "sway", "ShieldSoftBlue", 0f, "caocao", "", "", "");
```

### 孙权·制衡（2021031~2021035）— 新增 SkillAidBalance

> 制衡之道，为范围内最多/targetcount名友军随机附加一种强化（攻速/移速/伤害提升），持续/bufftime秒

- 随机池 { 快 300005（攻速）/ 翼 300010（攻速+移速）/ 重 300004（伤害提升）}，三者均读 `skillCfg.Strength`，数值语义统一为比例，不冲突
- 实现：对每个选中友军 `SysRandom.Value` 随机取 1 个 buff 附加；已带同池任意 buff 的友军跳过（参照 SkillAidBuffArea 的 `!HasBuff(buffId)` 过滤）
- CD 8 / MP 16 / Range 100 / TargetCount 3→3→3→4→4 / BuffTime 6→6→7→7→7
- Strength = Strength2 = 0.10→0.14→0.18→0.22→0.25（Strength2 供翼的移速使用）

```csharp
config[2021031] = new SkillConfig(2021031, "制衡", "孙权", "制衡之道，为范围内最多/targetcount名友军随机附加一种强化（攻速/移速/伤害提升），持续/bufftime秒", "术", 1, 0f, 8f, 16, "", 0, "", 100f, 0f, "", 3, 0.10f, 0.10f, 0, "翼", false, 6f, "", 0, 0f, 0f, 0f, 0, "SkillAidBalance", "sway", "MagicChargeYellow", 0f, "sunquan", "", "", "");
```
