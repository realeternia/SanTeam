# 王职业英雄技能设计（方案稿 v2）

## 一、概述

王职业共 6 名英雄，当前 Skill1 均为占位"强"（未挂载个人技能），本次全部落地。技能 Id 段 **2021021~2021050**（6 人 × 5 级 = 30 行，已验证该段空闲）。

| 英雄 | heroId | 阵营 | 品质 | 费用 | 技能 | 策略 | Id 段 |
|---|---|---|---|---|---|---|---|
| 刘备 | 100001 | 蜀 | 3 精良 | 6 | 仁德 | 全体友军 hero 回复强化（hp/mp） | 2021021~2021025 |
| 曹操 | 100002 | 魏 | 4 史诗 | 8 | 护驾 | 传送低血友军+套盾+回复加成 | 2021026~2021030 |
| 孙权 | 100003 | 吴 | 3 精良 | 6 | 制衡 | 永久随机提升攻/ap/双防 | 2021031~2021035 |
| 董卓 | 100004 | 群 | 3 精良 | 6 | 暴虐 | 范围友军伤害提升（简单粗暴） | 2021036~2021040 |
| 司马炎 | 100005 | 晋 | 2 普通 | 4 | 一统 | 范围友军减伤（简单粗暴） | 2021041~2021045 |
| 袁绍 | 100006 | 群 | 2 普通 | 4 | 名门 | 单体大将大量属性加成（走 buff） | 2021046~2021050 |

## 二、核心约定

- 全部为 **Aid 主动技能**（覆写 `CheckAidSkill`，`SkillManager.CheckAidSkill` 每帧轮询），`Rate=0` 必发、CD 到即放。
- 全部 `Type="术"`、`DamageType=0`（法术向统一）。
- Sname = 英雄名，与王职业技能"诸侯"（Sname="王"）不冲突。
- 描述全部用内联字段（`/strength`、`/strength2`、`/targetcount`、`/bufftime`）。
- Buff 的 Strength 取自**施放技能**的 skillCfg（Buff 基类已保证）。
- 复用现有 Buff：重 300004 / 硬 300002 / 盾 300001；新增 3 个 Buff（仁德/护驾/名门，300027~300029）。
- 技能类内 `BuffConfig.GetConfigByNameS` 判空记 `GameLog.Error`，禁止静默。

## 四、高品质 4 人详设（各新增 1 个技能脚本）

### 刘备·仁德（2021021~2021025）— 新脚本 SkillAidBenevolence + Buff 仁政

> 仁德之政，使我方全体英雄提升生命回复/strength点/秒、法力回复/strength2点/秒，持续/bufftime秒

- **全体**：`GetUnitsInRange(owner.pos, Range, side, false)` 过滤友军 hero（`isHero && IsInFight()`），**全部附加，不设 TargetCount 上限**
- **Buff 仁政**：新 Buff 300027（BuffHpMpRegen）——OnAdd `hpRegen += skillCfg.Strength`、`mpRegen += skillCfg.Strength2`，OnRemove 还原（hpRegen/mpRegen 为 Chess float 属性，OnSecond 事件按秒结算，直接提升回蓝/回血速度）
- CD 8 / MP 16 / Range 100 / BuffTime 6→6→7→7→8
- Strength（hpRegen/秒）6→7→8→9→10 / Strength2（mpRegen/秒）1→1.5→2→2.2→2.5

```csharp
config[2021021] = new SkillConfig(2021021, "仁德", "刘备", "仁德之政，使我方全体英雄提升生命回复/strength点/秒、法力回复/strength2点/秒，持续/bufftime秒", "术", 1, 0f, 8f, 16, "", 0, "", 100f, 0f, "", 0, 6f, 1f, 0, "仁", false, 6f, "", 0, 0f, 0f, 0f, 0, "SkillAidBenevolence", "sway", "MagicChargeYellow", 0f, "liubei", "", "", "");
```

```csharp
config[300027] = new BuffConfig(300027, "仁政", "仁", "提升生命回复/strength点/秒、法力回复/strength2点/秒", true, "BuffHpMpRegen", "", "", "", "");
```

### 曹操·护驾（2021026~2021030）— 新脚本 SkillAidImperialGuard + Buff 护驾

> 护驾亲临，将生命比例最低的友军英雄传送到身边，套/strength2%最大生命护盾，并提升其受疗/strength%，持续/bufftime秒

- **传送**：选范围内（Range 80）友军英雄中 `hp/maxHp` 最低者，`lowest.MoveTo(owner 身边偏移, true)`（参照 SkillAttackedTeleport 的 MoveTo 瞬移，走 CombatLayer 直接改位）
- **套盾**：Strength2 存盾% maxHp，`(buff as BuffShield).SetHp((int)(lowest.maxHp × Strength2))`（参照李严护军）
- **回复加成**：Buff 护驾（BuffHealBoost）——OnAdd `healedRate += skillCfg.Strength`、OnRemove 还原（healedRate=受治疗系数，0.1=受疗+10%）
- CD 10 / MP 18 / Range 80 / BuffTime 5→5→6→6→7
- Strength（受疗+）0.15→0.20→0.25→0.28→0.30 / Strength2（盾%）0.20→0.25→0.30→0.35→0.40

```csharp
config[2021026] = new SkillConfig(2021026, "护驾", "曹操", "护驾亲临，将生命比例最低的友军英雄传送到身边，套/strength2%最大生命护盾，并提升其受疗/strength%，持续/bufftime秒", "术", 1, 0f, 10f, 18, "", 0, "", 80f, 0f, "", 0, 0.15f, 0.20f, 0, "护", false, 5f, "", 0, 0f, 0f, 0f, 0, "SkillAidImperialGuard", "sway", "ShieldSoftBlue", 0f, "caocao", "", "", "");
```

### 孙权·制衡（2021031~2021035）— 新脚本 SkillAidBalance

> 制衡之道，为范围内最多/targetcount名友军英雄永久随机提升攻击或ap/strength点、护甲或魔抗/strength2点

- **永久属性**：直接改 Chess 字段，不走 buff 不还原（参照黄月英巧工先例）
- **随机池四选一**（`SysRandom`）：攻击 `atk += Strength` / ap `ap += Strength` / 护甲 `armor += Strength2` / 魔抗 `magicRes += Strength2`，每人随机一项
- 范围友军 hero 随机选 TargetCount 人（`WorldManager.RandomSelect`，参照 SkillAidBuffArea）
- CD 8 / MP 16 / Range 100 / TargetCount 3→3→4→4→5
- Strength（攻/ap）12→18→24→30→36 / Strength2（双防）8→12→16→20→24

```csharp
config[2021031] = new SkillConfig(2021031, "制衡", "孙权", "制衡之道，为范围内最多/targetcount名友军英雄永久随机提升攻击或ap/strength点、护甲或魔抗/strength2点", "术", 1, 0f, 8f, 16, "", 0, "", 100f, 0f, "", 3, 12f, 8f, 0, "", false, 0f, "", 0, 0f, 0f, 0f, 0, "SkillAidBalance", "sway", "MagicChargeYellow", 0f, "sunquan", "", "", "");
```

- 王职业技能"诸侯"（Dumb 被动，LinkSelf 属性 + 阵营护盾额外%）不受影响，与个人技能叠加。
- 高品质 4 人定位差异：刘备=群体续航、曹操=救急保人、孙权=永久成长、袁绍=单体核心强化；低品质 2 人=范围简单 buff，体现费差。

- 新增 .cs 由 csproj 通配 include 自动纳入，无需改 Assembly-CSharp.csproj。
