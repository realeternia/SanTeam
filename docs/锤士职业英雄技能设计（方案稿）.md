## 二、核心实现约定（沿用工程既定规范）

1. **全部做成 aid 技能**：覆写 `Skill.CheckAidSkill()`，由 `SkillManager.CheckAidSkill` 每帧轮询自动施放，复用 `CheckBurst` 处理 CD/MP；`Rate=0` 必发。
2. **伤害类型**：锤职破甲向偏向**武力/物理**（`DamageType=1`，走 `GetSkillDamage() = Strength + atk`）；士职为保护向，若无伤害则不受类型约束。**具体待用户确认后统一**。
3. **破甲/破盾复用现成钩子**：无视护甲走 `Skill.GetArmorDelta(isAttackerSide)` 返回 -1；击破护盾走 `Chess.OnSkillDamaged(..., CombatConst.AntiShieldHurtTag)`（该标签绕过 BuffShield 直接打血）。
4. **数值全部进 `SkillConfig`**；技能**专属**机制数值（嘲讽范围、破盾倍率等）写成脚本 `public const / private const`，不堆进 `CombatConst`。
5. **僵尸 Buff 复用现成**：护盾=盾(300001)、减伤盾=硬(300002)、攻击加=攻(300008)、易伤=伤(301003)、降甲=破；**嘲讽需新增 `BuffTaunt`**（见第五节）。
6. `Descript` 仅 `Lv1` 填完整模板，数值处内联 `/字段` 动态引用；**Lv2~5 留空**，显示时按该等级行字段自动替换。
7. **类名用英文**（`SkillAidXxx`，按效果、无职业/人名前缀），`Sname=英雄名`。

### SkillConfig 构造参数（当前 38 参，排布）

```
Id, Name, Sname, Descript, Type, Lv, Rate, CD, MpCost, TriggerCondition,
DamageType, HurtTag, Range, Area, TargetType, TargetCount, Strength, Strength2, StrengthInt,
BuffId, NegBuff, BuffTime, SummonTag, SummonCount, SummonTime, SummonHitInterval, SummonSpeed,
ItemId, ScriptName, Action, HitEffect, EffectSize, Icon, LinkSelf, LinkTeam, AuroAttrs
```

## 五、新增机制：嘲讽（BuffTaunt）与生命链接（BuffLifeLink）

士职需要的新机制：**嘲讽**（赵云/李严/庞德/黄盖用）与**生命链接**（张梁用）；李典/黄盖的护盾复用现成 Buff「盾」/「硬」，不新增。少量改动索敌/伤害逻辑：

### 1. BuffTaunt（嘲讽）

- **作用**：持有者成为敌对单位强制优先攻击的目标。
- **实现**：
  1. 新增 `Buff/Taunt.cs` 类（Buff 基类），佩戴单位身上有嘲讽标记。
  2. 在 `SkillManager` / `WorldManager` 维护「嘲讽单位」识别：`Chess.FindTarget()` 索敌打分时，若敌方存在带 `BuffTaunt` 的存活单位，则将该单位作为最高优先级锁定目标（可判定"范围内最近嘲讽者优先"）。
  3. `CheckAidSkill` 施放时为 `/area` 范围内敌方单位"对施放者挂嘲讽"——实际是施放者主动立（不改变敌方单位），敌方 `FindTarget` 每帧读取"是否有人嘲讽"。
  4. 在 `BuffManager.AddBuff` switch 注册 `case "Taunt"`。

### 2. BuffLifeLink（生命链接·张梁）

- **作用**：持有者（友军）与张梁各自挂链接，双方受到的伤害与治疗 / 恢复按 `/strength2%` 相互共享，双向分摊、双向回血。
- **实现**：
  1. 新增 `Buff/LifeLink.cs` 类：覆写受害侧 `BeforeCalDamaged`（把 `/strength2%` 伤害反向转给链接方）与治疗侧回调（把 `/strength2%` 治疗转给链接方）。
  2. 施放时对目标与自身各挂一份，两端引用彼此。
  3. `BuffManager.AddBuff` switch 注册 `case "LifeLink"`。

> 说明：嘲讽涉及索敌打分改动（改 `Chess.FindTarget`），属**架构改动**，需用户确认后实施。
