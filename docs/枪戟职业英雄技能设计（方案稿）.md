## 二、核心实现约定（沿用工程既定规范）

1. **全部做成 aid 技能**：覆写 `Skill.CheckAidSkill()`，由 `SkillManager.CheckAidSkill` 每帧轮询自动施放，复用 `CheckBurst` 处理 CD/MP；`Rate=0` 必发。
2. **法术伤害**统一 `DamageType=0`，`Type="术"`，单体/常规伤走 `GetSkillDamage() = Strength × (100 + ap) / 100`；若某辅助参数占用 `Strength`，则该技能的伤害 base 改放 `Strength2` 并在逻辑内按 `Strength2 × (100 + ap) / 100` 结算。
3. **控制 / 增伤类 Buff 尽量复用现有短名**；仅张辽·威震的"反伤"需**新增 BuffReflect**（BuffConfig 300025，短名"反"）。
4. **数值全部进 `SkillConfig`**；技能**专属**的机制数值写脚本 `const`，不堆进 `CombatConst`。
5. `Descript` 仅 `Lv1` 填完整模板，数值内联 `/字段`（`/strength`、`/strength2`、`/strength2%`、`/strengthint%`、`/bufftime`、`/area`）；**Lv2~5 留空**，显示时按该等级行字段自动替换。
6. **类名用英文**（`SkillAidXxx`，按效果、无职业/人名前缀），`Sname=英雄名`。

### SkillConfig 构造参数（36 参，排布）

```
Id, Name, Sname, Descript, Type, Lv, Rate, CD, MpCost, TriggerCondition,
DamageType, HurtTag, Range, Area, TargetType, TargetCount, Strength, Strength2, StrengthInt,
BuffId, NegBuff, BuffTime, SummonTag, SummonCount, SummonTime, SummonHitInterval, SummonSpeed,
ItemId, ScriptName, Action, HitEffect, EffectSize, Icon, LinkSelf, LinkTeam, AuroAttrs
```

### 2. 张辽·威震（5 费/史诗 · 反伤 + 高眩晕状态）— `SkillAidVengefulStance`

**机制（防守战士状态技）**：获得一个**威震状态**`/bufftime` 秒，期间：
- **高眩晕**：自身**普攻**按 `/strengthint%` 概率眩晕目标（复用 Buff `威` BuffHitStun，眩晕 2s）；
- **反伤**：受到伤害时把其中 `/strength` 比例**反还给攻击者**（物理/魔法伤害来源都能反，新增 Buff `反` BuffReflect）。

| 1 | 40 | 0.15 | 5s | 7s | 16 |
| 2 | 45 | 0.20 | 5s | 7s | 16 |
| 3 | 50 | 0.25 | 6s | 7s | 16 |
| 4 | 55 | 0.30 | 6s | 7s | 16 |
| 5 | 60 | 0.35 | 7s | 7s | 16 |

Descript：`威震逍遥津，获得威震状态持续/bufftime秒：期间普攻有/strengthint%几率眩晕目标，并把受到伤害的/strength%反还给攻击者`

> 该行 `BuffId="威"`（BuffHitStun），反伤 `Buff`「反」由脚本按常量短名另加；随机眩晕走 `SysRandom`。

## 九、平衡说明与风险

1. **用户修订点（本次 V2 相对 V1）**：马谡改单体减速；张辽改"反伤 + 高眩晕状态"（无直接伤害）；张绣改纯范围法伤；曹真改纯单体法伤；文丑改范围法伤 + 目标最大生命%额外伤害。于禁 / 孙坚 / 魏延 / 典韦 / 孙策 / 蒋钦维持 V1。
2. **张辽状态技**隐形的"眩晕收益"较高，故本体无直接伤害、MP 16 / CD 7s；眩晕概率 40%~60% 走 `SysRandom`，反伤 15%~35%；反伤需接入受击结算钩子（物/法统一），落地时确保不触发自身反伤无限循环（当反伤来源也是带反伤单位时需加防环）。
3. **文丑生命%**：总伤 = `/strength`法术伤 + `/strength2×目标maxHp`，对大血牛有显著收益、对脆皮偏低；`Strength` base 较高（80~235）以承担主要输出，MP 18 / CD 8s 制约其高频。
4. **单体 vs 群体**：张辽/曹真/马谡等单体按 MP/CD 错开，群体（张绣/魏延/典韦/文丑/蒋钦）单段低于单体爆；孙策/文丑为高费高伤档，依托更大耗蓝。
5. **字段冲突约定**：张辽 `Strength`（反伤比）与 `StrengthInt`（眩晕概率）并存、`Strength2` 留空；文丑 `Strength`（base 伤）与 `Strength2`（生命%）并存；于禁 `Strength`（减伤）与 `Strength2`（微法伤 base）并存——伤害在脚本内按需计算，不走 `GetSkillDamage()`（它只吃 `Strength`）。
6. **Descript 占位**：`Lv1` 完整模板 + `/字段` 内联；`/strength2%`（0.08→8%）、`/strengthint%`（40→40%）、`/strength2`（流失/削值整型）走既有 `SubstituteFieldRefs` 分支；Lv2~5 留空自动替换。
7. **异常点（落地时重点）**：孙策直线穿透重复命中控制；于禁/张辽同一技能内加多个自身/敌方 buff（BuffId 一槽一个，其余走类常量）；张辽反伤防递归、眩晕概率用 `SysRandom`；新 BuffReflect 需注册 `BuffManager` 与新增 BuffConfig 300025。
8. 落地后核对：旧 `Sname="强"` 无残留、`HeroConfig.Skill1` 挂英雄名、`SkillManager` 11 个 case 与 `SkillConfig.ScriptName` 一一对应、`BuffManager` 已注册"反"、MSBuild Release 编译通过、headless 全员阵容验证 11 个技能 `isBurst=True` 且无异常。
