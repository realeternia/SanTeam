## 二、核心实现约定（沿用工程既定规范）

1. **全部做成 aid 技能**：覆写 `Skill.CheckAidSkill()`，由 `SkillManager.CheckAidSkill` 每帧轮询自动施放，复用 `CheckBurst` 处理 CD/MP；`Rate=0` 必发。
2. **伤害类型**：棋/扇均为**法术伤害**（`DamageType=0` / `Type="术"`），走 `GetSkillDamage()` = `Strength × (100+ap)/100`，受魔抗减免。
3. **减益 Buff 尽量复用现成短名**：
   - 增伤/易伤 = 伤(301003)、减攻 = 慑(300013)、减疗 = 疫(300014)、减速 = 缓(300020)/慢(301004)、持续dot = 败(301006)、眩晕 = 乱(301001)、倍击 = 倍(300017)。
   - 本文档**全部复用现成 Buff，不新增**。
4. Buff 配在 `skillCfg.BuffId`（短名）；主动技向目标挂减益直接经 `BuffManager.AddBuff` 施加。
5. 数值全部进 `SkillConfig`；技能**专属**机制数值写成脚本 `public/private const`，不堆进 `CombatConst`。
6. `Descript` 仅 `Lv1` 填完整模板，数值处内联 `/字段`；**Lv2~5 留空**。
7. **类名用英文**（`SkillAidXxx`，按效果降级、无职业/人名前缀），`Sname=英雄名`。

### SkillConfig 构造参数（38 参）

```
Id, Name, Sname, Descript, Type, Lv, Rate, CD, MpCost, TriggerCondition,
DamageType, HurtTag, Range, Area, TargetType, TargetCount, Strength, Strength2, StrengthInt,
BuffId, NegBuff, BuffTime, SummonTag, SummonCount, SummonTime, SummonHitInterval, SummonSpeed,
ItemId, ScriptName, Action, HitEffect, EffectSize, Icon, LinkSelf, LinkTeam, AuroAttrs
```
