## 二、核心实现约定（沿用工程既定规范）

1. **全部做成 aid 技能**：覆写 `Skill.CheckAidSkill()`，由 `SkillManager.CheckAidSkill` 每帧轮询自动施放，复用 `CheckBurst` 处理 CD/MP；`Rate=0` 必发。
2. **物理伤害**统一 `DamageType=1`，走 `Skill.GetSkillDamage() = Strength + atk`；**无位移**（不写偏移突进 / 跳跃协程）。
3. **数值全部进 `SkillConfig`**；技能**专属**的机制数值（连斩次数、追猎重选等）写成脚本 `public const / private const`，不堆进 `CombatConst`（`CombatConst` 只放跨技能复用的公共常量）。
4. **零新增 Buff / 召唤物 / 美术**：Buff（乱/盾/翼/伤/破）与召唤物（`CombatConst.SoldierShadow` 影分身）全部复用现成资源。
5. `Descript` 仅 `Lv1` 填完整模板，数值处内联 `/字段` 动态引用（`/strength`、`/strengthint%`、`/strength2%`、`/bufftime`、`/area`、`/summoncount`、`/targetcount`）；**Lv2~5 留空**，显示时按该等级行字段自动替换。
6. **类名用英文**（`SkillAidXxx`，按效果、无职业/人名前缀），`Sname=英雄名`。

### SkillConfig 构造参数（当前 38 参，排布）

```

BuffId, NegBuff, BuffTime, SummonTag, SummonCount, SummonTime, SummonHitInterval, SummonSpeed,
ItemId, ScriptName, Action, HitEffect, EffectSize, Icon, LinkSelf, LinkTeam, AuroAttrs
```

|---|---|

| SkillAidDualLaser.cs | 前方喷射 `/targetcount` 道穿透激光，每道对路径（`Area`）敌人各结算一次（流光·姜维） |
| SkillAidSmashStun.cs | 结算 + `BuffManager.AddBuff(目标, 乱, BuffTime)` |
| SkillAidSlashDefend.cs | 结算 + 自身挂"硬"`BuffTime`（御斩·乐进） |
| SkillAidBashShield.cs | `GetUnitsInRange(self, Area, 敌方)` 全打；自身挂"盾"`Strength2% 最大生命` |
| SkillAidExecute.cs | 结算；目标 `HpRate < StrengthInt` 则 `damage ×= Strength2` |
| SkillAidRandomCombo.cs | `n=SysRandom.Number(SummonCount, StrengthInt)` 次随机连击，每次 `/strength × atk`（追猎·马超） |
| SkillAidHasteStrike.cs | 结算 + 自身挂"翼"`BuffTime` |
| SkillAidMarkTarget.cs | 结算 + 目标挂"伤"`Strength2` / `BuffTime` |
| SkillAidDoubleShot.cs | 首选目标 + `TargetCount-1` 名附近敌人各结算一次 |
| SkillAidBerserk.cs | 自身挂新 Buff"狂"`BuffTime`；增伤/易伤均由 BuffFrenzy 读 `Strength2`（狂暴·华雄） |
| SkillAidSwapStrike.cs | 对目标结算 `/strength` 固定魔法伤害 + 与目标交换位置（换位·陈泰） |

## 九、平衡说明与风险

1. **单体 vs 群体**：关羽/颜良/夏侯惇等单体高伤技能按"高耗蓝换高伤"原则（MP 18），程普范围伤/韩当双射单段更低（MP 14），靠耗蓝错开，不碾压单体。
2. **随机连击（马超）**用 `Strength × atk` 段伤 + 随机次数（`SummonCount`~`StrengthInt`）控总输出；上限看脸、下限保底（2 次）。配车职业暴击可显著放大，故单次倍率设在 0.4~0.8，防一键爆炸。
3. **Descript 占位**：`Lv1` 填完整模板 + `/字段` 内联；`Lv2~5` 留空自动替换。`/strength2%`（如 0.25→25%）、`/strengthint%`（如 30→30%）均走既有 `SubstituteFieldRefs` 的 `%` 分支。
4. **影分身（关羽）**实时性较强，需验证落点不被 `TryLockGridPositions` 阻挡；若落点失败则就近空位放置（回落逻辑在 SkillAidShadowSplit 内处理）。
5. **Buff 成本**：除华雄狂暴需**新增** Buff`狂`(300022/BuffFrenzy) 外，眩晕/减防/易伤/自防/攻移速全部复用既有短名（乱/破/伤/硬/翼/盾），维护成本已尽量压低。
6. **异常点（落地时重点）**：陈泰"换位"用 `SetPosition` 交换与目标位置，需处理双方身位重置与近战索敌刷新；姜维"流光"为直线 AOE，需沿用飞斧的投射/穿透结算避免重复命中；华雄 BuffFrenzy 的受击加深要与普攻/技能/法术结算统一钩子接入。
7. 落地后核对：旧 `Sname` 无残留、`HeroConfig.Skill1` 已改挂英雄名、`SkillManager` 12 个 case 与 `SkillConfig.ScriptName` 一一对应、`BuffManager` 已注册"狂"、MSBuild Release 编译通过。
