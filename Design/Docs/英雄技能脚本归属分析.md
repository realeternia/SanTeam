# 英雄技能脚本归属分析

> 数据来源：`Assets/Resources/Scripts/Configs/HeroConfig_s.cs`（110 名英雄）、`Assets/Resources/Scripts/Configs/SkillConfig_s.cs`（819 行技能）、`Assets/Resources/Scripts/Combat/Skill/*.cs`（75 个 .cs 文件，含 `Skill.cs`/`SkillManager.cs`）。
> 口径：以每个英雄的**个人技能**（`HeroConfig.Skill1`）为准；取技能 Lv1 行做归属统计。品质：1 普通 / 2 优秀 / 3 精良 / 4 史诗。
> 本次变更：① 周瑜·火墙、庞统·连锁由普攻触发（Hit）改为主动辅助触发（Aid）；② 第一轮特化脚本合并——直接合并 5 个、补参数合并 28 个（33 个脚本下线、新增 `SkillTaunt` / `SkillSoldierSingle` / `SkillSoldierGrow`）；③ 第二批合并——`SkillAidCutSupply`（2 人）并入 `SkillSingleDamage(dot)`、`SkillAidLastingFocus`（马岱）并入 `SkillSelfBuff(permanent)`、`SkillAidJumpHeal` + `SkillAidJumpDamage` 合并为 `SkillJumpChain`，个人技能脚本数由 74 收敛到 **41**；④ 第三批合并——`SkillAidBacklineHunt`（文鸯·单骑）+ `SkillAidSuddenArrow`（郭图·强击，兼职业兵种技能「骑射」）合并为共享模板 `SkillBacklineStrike`，脚本数由 41 收敛到 **40**；⑤ 第四批合并——`SkillLowHpFullHealShield`（邓艾·偷渡阴平）并入 `SkillAttackedShield`（`ignoreWeakHit` 标记跳过弱伤害门槛、回血时长/数值口径自动分流），脚本数由 40 收敛到 **39**。

## 一、关联关系（代码事实）

| 环节 | 字段 | 说明 |
| --- | --- | --- |
| 英雄 → 个人技能 | `HeroConfig.Skill1` | 指向 `SkillConfig.Sname`（技能缩写）；一个 Sname 唯一归属一名英雄 |
| 技能 → 脚本类 | `SkillConfig.ScriptName` | 即 `Combat/Skill/` 下的类名，`SkillManager` 按此反射创建脚本实例 |
| 技能等级 | `SkillConfig.Lv` (1~5) | 个人技能展开 Lv1~5 行；界面/战斗按卡片等级取对应行。本表统一取 Lv1 行 |
| 技能分类 | `SkillConfig.Type` | 单伤/群伤/单控/群控/单增/群增/群疗/单疗/兵增/自增/召唤/光环等 |
| 脚本行为开关 | `SkillConfig.TargetType` | 合并后从“选取点”单值扩展为**标记列表**（逗号/分号/竖线分隔），由 `Skill.HasSkillFlag(flag)` 精确匹配；空串=默认行为 |

> 补充：除个人技能外，每名英雄还带一个**职业技能**（`JobConfig.NameS`，即职业缩写如 王/扇/枪…）；职业兵种技能、好友连锁技能、道具技能的 `Sname` 不是英雄名，不参与“英雄个人技能”归属。

### 各通用脚本机制说明

- **`SkillSingleDamage`**（26 人）：通用"单体伤害 + 可选增益/减益"。锁定 `Range` 内当前目标，造成 `GetSkillDamage()`；`TargetCount>0` 时对同一目标连打 N 段（荀攸·奇策），否则单段。BuffId 默认挂目标。
  `TargetType` 标记：`selfBuff`=BuffId 全挂自身（高览·御守 / 陈泰·扬鞭 / 程普·横扫，护盾类自动写护盾值）；`bothBuff`=首段挂目标、其余挂自身（马腾·腾驾）；`multiplier`=伤害×Strength2[0]（张任·毒箭）；`execute`=目标生命比例<Strength2[1] 时伤害×Strength2[0]（颜良·斩杀 / 乐进·御斩）；`shieldBonus`=目标带吸收盾时伤害×Strength2[0]（曹洪·裂盾）；`missingHp`=伤害 += 伤害×Strength2[0]×已损生命比例（孟获·蛮勇）；`armorIgnore`=自身普攻无视目标护甲（潘璋·偷刃 / 高顺·破甲）；`antiShield`=目标带盾时追加 Strength2[0] 倍破盾伤害并携带 AntiShield 标签（高顺·破甲）；`dispel`=伤害后驱散目标正面 Buff（许攸·傲言 / 张松·舌辩）；`dot`=附加每秒 Strength2[0] 的持续伤害，持续 BuffTime（李儒·鸩酒、程昱·断粮、蒋钦·江河）。
- **`SkillAreaDamageDeBuff`**（12 人）：通用"范围伤害 + 减益"。范围中心由 `self` 标记决定：有 `self`=自身中心（近战贴脸 AoE，不做射程校验，如张绣·枪出如龙 / 孙坚·破阵 / 刘晔·卸甲）；缺省=目标中心（需在 `Range` 内，`Range<=0` 视为不限射程，如张郃·震碎 / 司马昭·篡逆 / 钟会·蓄谋 / 庞统·连锁）。取中心 `Area` 半径内敌人（`TargetCount>0` 时随机 N 名，`<=0` 时全部）造成伤害并附加 BuffId 减益。
  扩展标记：`missile`=以飞弹逐个结算、伤害×(1+Strength2[0])（黄忠·乱射）；`maxHpBonus`=伤害 += 目标最大生命×Strength2[0]（文丑·陷阵怒吼）。
- **`SkillSelfBuff`**（12 人）：通用"自身增益"。触发时给施法者自身挂 1~N 个 Buff（BuffId 逗号/分号分隔），数值由各 Buff 自身读取 Strength2/StrengthBuff1，时长取 BuffTime；护盾类 Buff 自动按 `GetSkillShield(0)` 写入容量（周泰·不屈）、减伤盾「硬」读 StrengthBuff1[0]。
  扩展标记：`noStack`=自身已带任一 BuffId 时不重复施放（曹仁·天人守城，叠层与到期还原由 `BuffDefStack` 负责）；`permanent`=不挂 Buff，直接把 Strength2[0] 永久累加到自身攻速（马岱·连射）。
- **`SkillAreaBuff`**（10 人）：通用"群体增益"。给范围内友军附加 BuffId 对应的正面 Buff，支持多段组合（如"攻,甲,抗"），`TargetCount>0` 取 N 名、`<=0` 取范围内全部；护盾类 Buff 自动写入护盾值。
  `TargetType` 标记：`heroOnly`=只选英雄（刘备·仁德 / 甄宓·洛神 / 袁绍·名门 / 周仓·忠勇）；`excludeSelf`=候选池排除施法者；`selfAlways`=施法者必定获得（李典·御阵 / 周仓·忠勇）；`lowestHp`/`highestHp`=按生命比例排序取前 N（甄宓 / 周仓 / 袁绍 / 李严）；`fullHpSkip`=跳过满血友军；`noDedupe`=不按首段 Buff 去重；`crossSideFallback`=同侧无目标时退到非敌对阵营（袁绍）；`wholeMap`=全图选人，Area 只作嘲讽半径（李严·护军）；`tauntAroundTarget`=挂完 Buff 后嘲讽目标周围 Area 内敌人（李严·护军）。
- **`SkillAura`**（6 人）：光环主动助战（鲁肃 / 诸葛瑾 / 田丰 / 费祎 / 司马师 / 孙乾）。保留 AuroAttrs 开局被动光环，施放时对本侧全体英雄（含自身）再永久累加 光环属性值×Strength2[0]；另为自身永久叠加成长属性（光环主属性为法强时叠 ap，否则叠 atk），并驱散我方全体英雄的负面 Buff。
- **`SkillAreaHeal`**（3 人）：先在 Area 内选出生命比例最低的友方英雄作为治疗中心，再以该中心为圆心、Area 为半径，按生命比例从低到高最多治疗 `TargetCount` 名友方英雄（吃医职业加成），治疗量走 `GetSkillHeal()`；全部满血时不施放。默认对受疗者驱散负面 Buff，BuffId 非空时附带对应 Buff（左慈·天书挂闪避）。
  扩展标记：`overflowToArmor`=溢出治疗量转为等量护甲（BuffId 需配"甲"，且不再附带驱散，刘禅·安乐）。
- **`SkillTaunt`**（3 人，合并新建）：对自身 Area 范围内敌人施加嘲讽（把这些敌人的当前目标改为自己），可按配置追加自身 Buff 与范围伤害。`requireTarget`=必须有当前目标才施放（于禁·铁壁）；`selfBuff`=BuffId 挂给自身（黄盖·苦肉、于禁·铁壁的减伤盾「硬」）。`DamageStrength>0` 时对 Area 内敌人结算 `GetSkillDamage()`（庞德·抬棺 / 于禁），为 0 时为纯嘲讽（黄盖）。
- **`SkillJumpChain`**（2 人）：通用"跳跃链"技能，医疗波 / 连锁闪电式连续跳跃。
  伤害模式（缺省，法正·明断）：首跳取当前索敌目标（须在 Range 内），随后每跳在 Area 内找最近且未命中的敌人，共 TargetCount 跳；每跳造成 `GetSkillDamage()` 并附加 BuffId 减益，逐跳 ×0.85，间隔 0.3s。
  治疗模式（`heal`，张宝·妖疗）：首跳选 Area 内生命比例最低的友方英雄，随后每跳找最近且未治疗的友方英雄，共 TargetCount 跳；每跳按 `GetSkillHeal()` 治疗，逐跳 ×0.85，间隔 0.2s。
- **`SkillShockWave`**（2 人）：通用方向型范围导弹。朝目标位置发射导弹，由飞行中的导弹逐个命中路径敌人结算（最多 `TargetCount` 名）；配置 BuffId 时额外挂该 Buff（惊雷减速），未配置则不挂（虎啸）。
- **`SkillSoldierGrow`**（2 人，合并新建）：本侧士兵永久叠加 `Strength2[0]` 比例攻击；第二条数值按标记写入护甲或攻速。`archers`=只作用于弓兵（沮授·强弓）；`selfToo`=施法者自身同步获得加成；`haste`=Strength2[1] 作为攻速加成（沮授），缺省作为固定护甲（马良·励军）。
- **`SkillSoldierSingle`**（2 人，合并新建）：从本侧存活士兵中选 1 名，按配置回满血并/或附加 Buff（护盾类自动写入护盾值）。`meleeOnly`=只选近战士兵（蒋琬·抚军）；`lowestHp`=选生命比例最低者（张昭·筑垒），缺省随机；`fullHeal`=先回复满血；`selfFallback`=场上无士兵时改为对自身施放。
- **`SkillBacklineStrike`**（2 人，合并新建）：优先打后排的单体射击，搜索半径 `Area>0 ? Area : max(attackRange, Range)`，通过飞弹 `CreateSpellMissile` 结算 `GetSkillDamage()`。默认取搜索范围内距离最远的敌人（文鸯·单骑）；`smart`=三层距离带降级（远段 70%~100% → 中段 50%~70% → 全局）+ 英雄优先 + 每层取对应抗性最低者（郭图·强击、职业兵种技能「骑射」）；`extra`=伤害追加 `Strength2[0]` 比例，即基础伤害 ×(1+Strength2[0])（文鸯·单骑）。
- **`SkillAttackedShield`**（2 人，合并新建）：受击时给自己施加吸收盾/减伤盾，触发由 `Skill.CheckBurst` 统一判定（CD、概率、MpCost、TriggerCondition）。BuffId 第 1 段为盾：「盾」容量 = `GetSkillShield(0)`，「硬」减伤率读 StrengthBuff1[0]；第 2 段为可选回血「愈」。回血时长：StrengthBuff1 长度≥3 时取 [2]（益壮，固定值模式）；否则取 BuffTime（邓艾，每秒回血回退到 `GetSkillHeal()`）。`ignoreWeakHit`=不忽略 10 点以下弱伤害（邓艾·偷渡阴平），缺省时 `damage<=10` 不触发（严颜·老当益壮 / 益壮）。

## 四、专属/特化脚本（仅 1 名英雄，定制实现）

这些脚本各自实现了单英雄独有机制，无法用现有通用模板覆盖，故单独落一个脚本类（“特化”原因见末列）。

| 脚本 | 技能名 | 英雄（品质·职业） | 分类 | 特化原因 / 特殊机制 |
| --- | --- | --- | :--: | --- |
| `SkillAidBurstShot` | 连珠（太史慈） | 太史慈（史诗·弓） | 群伤 | 朝前方多发箭矢，距离越近伤害越高。每目标近度 near = max(0, 1 - dist/Range)，伤害 = 基础技能伤害 × (1 + Strength2[0] × near)。 |
| `SkillAidCavalryStrike` | 铁骑冲（马超） | 马超（史诗·马） | 群伤 | 两段冲锋：先沿朝目标方向突进 Range 距离，再原路撤回起点。每段对冲撞路径上的敌人各结算一次 GetSkillDamage 并施加减防 Buff（"破"），每段最多命中 TargetCount 名、同一段内同一敌人只命中一次（跨段可再吃一次）。 |

## 六、口径与易错点

1. **同一脚本可被多个技能共用**：如 `SkillSingleDamage` 被 24 名英雄的个人技能共用，它们共享脚本但 `Sname`/技能名/数值各异，是多个不同的技能而非一个。
2. **脚本也服务于非个人技能**：部分脚本同时被职业兵种技能占用（如 `SkillAttackRunCrossPlus` 同时是“冲·铁骑”兵种技能），因此“脚本数 ≠ 个人技能数”。
3. **本表以 Lv1 行统计归属**：个人技能 `Sname` 唯一归属一名英雄，Lv1~5 是同一技能的 5 个等级行，不重复计。
4. **“特化”判定**：只服务单一英雄个人技能即视为特化/专属脚本；多名英雄共用即视为通用模板。
5. **Range<=0 语义**：`SkillAreaDamageDeBuff` / `SkillAidFireWall` 中 `Range<=0` 视为不限射程（庞统·连锁 Range=0，改造后按此语义施放）。
6. **Hit → Aid 的差异**：Hit 型只在普攻结算时判定，Aid 型在 `Chess.Update` 中每帧经 `SkillManager.CheckAidSkill` 判定，满足 `CD + MpCost + Rate + TriggerCondition` 即主动施放，且触发当帧跳过普攻。
7. **`TargetType` 的语义已扩展**：合并后它表示“行为标记列表”，不再只是选取点。解析走 `Skill.HasSkillFlag`（按 `, ， ; ； |` 切分后精确匹配），因此标记名不能与旧的选取点值混写；空串代表模板默认行为。

### 7.4 结论

- **累计下线 40 个特化脚本**（第一轮 33 个 + 第二批 4 个 + 第三批 2 个 + 第四批 1 个），个人技能脚本总数由 **74 → 39**：
  - 庞统·连锁（`SkillHitBuffArea` → `SkillAreaDamageDeBuff`，Aid 改造后同构）；
  - 第一轮：7.1 直接合并 **5 个** + 7.2 补参数合并 **28 个**，新建 `SkillTaunt` / `SkillSoldierSingle` / `SkillSoldierGrow`；
  - 第二批：`SkillAidCutSupply`（程昱·断粮 / 蒋钦·江河）→ `SkillSingleDamage` + `dot`；`SkillAidLastingFocus`（马岱·连射）→ `SkillSelfBuff` + `permanent`；`SkillAidJumpHeal`（张宝·妖疗）+ `SkillAidJumpDamage`（法正·明断）→ 新建 `SkillJumpChain`（`heal` 标记区分）；
  - 第三批：`SkillAidBacklineHunt`（文鸯·单骑）+ `SkillAidSuddenArrow`（郭图·强击，兼职业兵种技能「骑射」）→ 新建共享模板 `SkillBacklineStrike`（默认最远 / `smart` 三层抗性选人 / `extra` 追加伤害）；
  - 第四批：`SkillLowHpFullHealShield`（邓艾·偷渡阴平）→ `SkillAttackedShield`（`ignoreWeakHit` 跳过 10 点弱伤害门槛，回血时长/数值口径按 StrengthBuff1 自动分流）。
- **保留 26 个**特化脚本：位移、引导、召唤、受击触发、独有选目标等，合并会引入大量开关，收益低于维护成本。
- 合并后结构：**39 个脚本 = 13 个通用模板（承载 84 名英雄）+ 26 个特化脚本（26 名英雄）**。

> 可选后续：`SkillHitWall`（道具·火箭）与 `SkillAidFireWall`、`SkillCastingAidScorchedEarth` 的持续跳伤循环高度重复，可抽一个“法术场持续伤害”基类，仅共享 tick 逻辑，不改变各自触发方式。
