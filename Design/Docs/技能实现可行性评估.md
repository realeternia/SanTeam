# 技能实现可行性评估（基于“常见自走棋/回合战斗技能体系”的假设）

## 前言 / 注记
- 我尝试读取仓库以做精确对比但当前没有对仓库源码的直接读取权限；以下结论基于常见技能系统的能力集（可配置的技能模板、效果类型、条件分支、被动/召唤/任务进度、护盾/治疗/减速/眩晕、持续与瞬发、按目标或范围等）。
- 文档合并了你提供的 1-2 费、3 费、4 费英雄技能条目，并对每个技能给出“可配置性 / 说明 / 缺失机制”评估。
- 输出分三部分：一是“需要引入/完善的全局机制”清单；二是逐个技能的可配置性评估与缺失说明（按你提供顺序）；三是优先级与开发建议。

## 一、建议新增 / 必要支持的全局机制（若你们已有可忽略）
按能力优先级列出，便于开发排期：

1. 条件分支技能（if target.hp% < X then ...）：需要技能表达式/条件子句（target属性判断、战斗状态检查、友军/敌军计数）。
2. 持久/跨战斗任务/成长（例：奥恩“锻炉能量”、乐芙兰复制几率、维迦永久法强）：需要 session/玩家持久进度存储 + 在关卡/战斗间触发与奖励发放机制。
3. 可叠加/永久增益（击杀后永久+法强、每次获得锻造能量生成物品等）：需要持久 stat 增益与限制（是否到星级/单位的生效时点）。
4. 技能替换/普攻替换（“下一次攻击被替换为猛击”、“每第3次普攻变为狙击”等）：需要攻击队列与攻击替换钩子、计数器、持续次数管理。
5. 通道/引导技能（按秒消耗法力、每秒造成伤害）：需要持续性技能执行（每个 tick）与打断判定，及“每秒消耗%最大法力”的资源模型。
6. 持续/周期性治疗或护盾（在一段时间内持续回复/持续失效）：需要 DOT/HoT/持续护盾的状态效果系统（可能以每 tick 应用）。
7. 召唤与嘲讽单位（召唤夜幽游灵并嘲讽）：需要召唤物种、生命/行为AI（嘲讽/仇恨优先），以及召唤物的星级/强度标注。
8. 技能穿透/穿透伤害随目标数衰减（穿过敌人伤害降低X%）：需要 projectile 轨迹与命中衰减模型，或对命中链计数器。
9. 状态/负面效果复用（灼烧、重伤/重伤效果降低治疗、魔抗削减/护甲削减、眩晕、减速、沉默等）：需要通用的状态效果系统、优先级与持续时间、与攻击/治疗互动逻辑。
10. 目标选择的复杂逻辑（生命最低、邻格、命中最多敌人的直线、锥形目标等）：需要丰富的目标选择器（按格子/邻格/直线/锥形/范围/生命排序）。
11. 条件目标类型识别（“如果目标是坦克”）：需要单位标签（role/tag）系统并在技能条件中暴露。
12. 次级/分裂弹/连锁伤害（例如分裂造成若干目标伤害）：需要链式目标分配与次级伤害配置。
13. 技能暴击/技能触发暴击概率与暴击效果（“技能暴击”）：需要将暴击机制拓展到技能来源而非仅普攻。
14. 随机/概率触发与掉落（10%几率生成额外蘑菇、复制、红蘑菇/绿蘑菇等）：需要 RNG 事件与掉落/持久拾取物系统（并同步到玩家界面）。
15. 资源/法力模型的灵活度（不同单位法力消耗模式：0 cost/按秒消耗/多段消耗/多层法力体系）：需要在单位数据结构中支持 maxMana、currentMana、mana-per-tick、额外回复等。

若你们已有这些机制则可直接配置；若部分缺失，按业务优先实现（例如跨战斗任务/永久增益通常工作量大但影响显著）。

### 3 费组（新增项）

- 克格莫（天降重炮）
  - 可配置性：可配置（部分细节）
  - 说明：对目标及最近的另一个敌人造成法术伤害并附加 3s 持续额外伤害（DoT）；对低生命目标额外伤害为条件分支。
  - 缺失机制：若无条件分支与 DoT 支持需补；如果“喷射到最近的敌人”涉及链式目标选择需要目标选择器。

- 卡兹克（品尝恐惧）
  - 可配置性：可配置
  - 说明：跃向最远敌人并造成伤害；若目标“孤立”（邻格无友军）则提高伤害并返还法力（并有跨单位法力共享触发到雷恩加尔）。
  - 缺失机制：需要邻格检测与“把法力提供给另一个特定英雄”的跨单位触发/转发逻辑（或 event-bus）。

- 卡西奥佩娅（瘟毒爆炸）
  - 可配置性：部分可配置
  - 说明：对目标和另一个未中毒敌人施加可叠加毒素（长期 DoT，15s），毒素可叠加增加总伤害。
  - 缺失机制：可叠加长期 DoT 的计时/叠加处理与“未中毒敌人”的筛选（状态检查）。

- 崔丝塔娜（爆炸火花）
  - 可配置性：部分可配置
  - 说明：附着型效果：为期 4s 的攻击速度增益并无限射程，期满爆炸按半径分摊伤害；若目标先倒下则转移到新目标。
  - 缺失机制：附着/陷阱型技能（带转移逻辑）与“爆炸伤害按周围敌人平均分摊”的实现；攻击替换与无限射程的处理需要明确（射程规则扩展）。

- 拉莫斯（尖刺防御）
  - 可配置性：可配置
  - 说明：嘲讽（仇恨吸引）、护盾与临界破护盾触发小范围反伤（伤害按护甲/魔抗比例）。
  - 缺失机制：护盾破裂事件钩子（触发反伤）需支持；若没有按防御属性按比例转化为伤害需补。

- 易（无极剑道）
  - 可配置性：可配置
  - 说明：被动：每第3次攻击双重打击（攻击计数与替换），并根据“魔战士”分支有额外魔法伤害与吸血/攻速叠加。
  - 缺失机制：若没有“第 N 次普攻替换成双击”和对额外伤害进行回复计算的支持需补。

- 深红锋喙鸟（鸟群之家）
  - 可配置性：可配置
  - 说明：召唤 4 个不可选小单位（持续若干秒）同步攻击主目标，产生额外攻击并可能降低护甲（被动）。
  - 缺失机制：召唤不可选单位与随主攻击同步攻击的代理逻辑（士兵/小分身 attack proxy）。

- 蔚（狂怒之拳）
  - 可配置性：可配置
  - 说明：被动普攻回复（每击），主动短时间获得高攻速+减伤+控制免疫（整段为 buff）。
  - 缺失机制：若系统没有控制免疫、短期多属性 Buff 需补。

- 费德提克（收获）
  - 可配置性：可配置
  - 说明：降魔抗（debuff），随后在 2s 内持续吸血并伤害多名目标（持续吸血与多目标 DoT）。
  - 缺失机制：无重大缺失（需确保“净化/限制效果”相关逻辑兼容）。

- 赫卡里姆（恐惧之灵）
  - 可配置性：可配置
  - 说明：短期护甲魔抗提升 + 持续回复 + 召唤幽魂骑兵对最近 3 名敌人造成伤害并晕眩。
  - 缺失机制：召唤小兵并附带控制（晕眩）需实现。

- 远古石甲虫（岩之摇滚）
  - 可配置性：可配置（部分）
  - 说明：被动倒下分裂成两个小体（嘲讽），主动增加 maxHP 并滚向目标造成混合伤害；倒下时对友军提供按最大生命值的护盾（若有蓝灰霸符）。
  - 缺失机制：单位分裂召唤与倒下时触发范围护盾、分裂体的 AI/不可选属性需支持。

- 阿兹尔（沙兵现身）
  - 可配置性：可配置（若已有士兵/代理攻击系统）
  - 说明：接下来的 6 次攻击转换为召唤士兵的指令，士兵代表延迟代理攻击造成魔法伤害。需要攻速与攻击代理计数。
  - 缺失机制：若没有“代理攻击（士兵代替）”与士兵生命周期需补。

- 雷恩加尔（无情）
  - 可配置性：可配置
  - 说明：跳向生命%最低并刺击，随后治疗（治疗量有最小/最大值基于已损失生命），并可将治疗转移给同盟（世纪和解）。
  - 缺失机制：跨单位治疗分享（把治疗分配给另一个单位）需 event/target routing。

- 黛安娜（苍白屏障）
  - 可配置性：可配置
  - 说明：短护盾 + 发出 6 颗法球按半径分摊伤害（各球减幅随距离）。
  - 缺失机制：伤害按距离衰减的分摊模型需支持（或者 radial falloff 支持）。

### 4 费组（新增项）

- 伊泽瑞尔（自然之怒）
  - 可配置性：部分可配置
  - 说明：瞬发位移并造成伤害与攻速增益；每第四次施放产生贯穿波并按穿透衰减（每通过降低 25%，下限 50%）。

  - 缺失机制：基于攻速动态决定打击次数的机制、以及连续挥击期间的动作替换与最终一次的分摊需实现。

- 墨菲特（石化树皮）
  - 可配置性：可配置
  - 说明：短期大量护盾并进入石化状态；护盾被打破时释放范围能量并造成伤害（伤害按护甲/魔抗比例）。
  - 缺失机制：护盾破裂触发事件与按目标防御属性计算的反弹伤害需实现（若已有则直接配置）。

  - 缺失机制：形态切换（stat & attack pattern 切换）、基于敌人“携带最少装备”的选择器、无视护甲部分及基于目标已损失生命值的增幅逻辑。

## 三、总结性优先级建议（实现顺序）

- 优先 1（高价值、低到中等实现复杂度）
  - 攻击替换计数器（普攻第 N 次替换、替换接下 N 次攻击）
  - 被动/召唤与嘲讽（通用召唤单元与仇恨标记）
  - 持续/通道型技能（引导按秒消耗/DoT/HoT）
  - 目标选择器扩展（生命最低、邻格、直线/锥形）

- 优先 2（中等复杂度）
  - 通道/按秒法力消耗技能（含打断）
  - 穿透弹道与 per-hit 衰减
  - 条件分支（基于目标 HP、标签、是否为坦克）

- 优先 3（高复杂度 / 跨战斗）
  - 永久/跨战斗成长 & 任务系统（奥恩、维迦、乐芙兰）
  - 掉落/拾取/道具生成系统（蘑菇与锻造器）
  - 概率/随机掉落与持久效果追踪（拾取计数、被动叠加）
