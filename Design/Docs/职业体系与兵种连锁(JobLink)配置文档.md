## 一、机制总览

- **兵种连锁（JobLink）**：金铲铲式职业羁绊。战斗开始时统计本侧同职业上阵英雄数，按档位施加被动属性加成，不走技能系统。
- **档位**：上阵该职业 **1/2/3/4/5 人** 分别解锁 **Lv1~5**，最高 5 级。
- **两列加成**（数值均在 SkillConfig 表中配置，不硬编码）：
  - **连接英雄加成（LinkSelf）**：该职业每个英雄自身获得的属性，各档位固定。
  - **我方其他英雄加成（LinkTeam）**：该档位下全队（含英雄与士兵）获得的总量，随档位提升。
- **Tooltip 展示**：英雄 tooltip 的职业技能行只显示当前档（绿色高亮）与下一档（灰色）；商店卡（上阵 0 人）默认显示 1 级档。

- **T0**：体系级核心——收益面覆盖全军（士兵/多单位）或乘区成长（攻速/百分比），随阵容规模滚雪球；
- **T1**：强势主力——数值优秀或带控制/概率特效，主流阵容常客；
- **T2**：过渡/功能位——数值中庸或受益面窄，特定阵容可用；
- **T3**：待加强——数值偏低或机制未实装，当前不建议主力培养。

>   - 光环通过 Buff 发放可以复用现有的 Buff 生命周期/可视化/移除逻辑（死亡/移动/换位时自动刷新）；

>   - 配置层面更直观，策划可在表中直接写 16%/24% 等并生成对应的 SkillConfig 字段；

## 四、配置说明

- **数据行**：`SkillConfig_s.cs`，Id 区间 2000011~2000165，`Type = "职业"`，每职业 5 行（Lv1~5），`Sname` 对应 `JobConfig.SkillId`。
- **加成格式**：`LinkSelf` / `LinkTeam` 字段，格式 `"attr+value,attr+value"`，如 `"armor+6,magicRes+6"`。对于光环类百分比建议写法 `"aura:atk+0.16"` 或 `"auraAtkRate+0.16"`。
- **属性缩写**：atk 攻击 / ap 法强 / might 武力 / armor 护甲 / magicRes 魔抗 / maxHp 生命 / critRate 暴击 / attackRate 攻速 / soldierAtk 士兵攻% / soldierHp 士兵生命% / auraAtkRate 光环攻击百分比 / auraDefRate 光环防御百分比 / debuffDur 负面持续倍率 / healRate 治疗加成 / mpRegen 法力回复 / hpRegen 生命回复
- **特殊规则**：
  - `soldierAtk`/`soldierHp` 仅对士兵生效（相）；
  - `LinkTeam` 为该档位总量，不再乘以人数；
  - 扇（羽扇）包含"碎片掉落"设计：技能施放后掉落魔法碎片，友军拾取后可回复法力或获得短期法强/加成（碎片逻辑为后续实现，当前以负面持续延长占位）；
  - 鼓为 AOE 光环：加成仅对鼓为中心一定范围内的友军生效（非全队），数值为原全队光环的约 2 倍；建议把光环通过 Buff 系统下发为按属性百分比的 Buff，支持与 `buffEffectRate` 叠加；
  - 琴为单体强化：连接英雄强化 1 名友军（建议优先攻击最高的英雄）并提升祝福效果比例，全队获得防御加成；实现时 JobLinkManager 需增加目标选择逻辑；
  - 枪（晕眩）与戟（AOE）为概率触发型效果：配置键 stunRate/aoeRate，复用 HitBuff（BuffId=301001 混乱）与 SkillHitArea（Burst/SkillDamageRate）实现；当前仅配置、数值联动需后续校准；
  - 弩已由"射程提升"改为"迅捷射手（攻速成长）"，原 range 规则不再适用。
