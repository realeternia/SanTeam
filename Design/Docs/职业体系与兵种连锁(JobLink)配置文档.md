## 一、机制总览

- **兵种连锁（JobLink）**：金铲铲式职业羁绊。战斗开始时统计本侧同职业上阵英雄数，按档位施加被动属性加成，不走技能系统。
- **档位**：上阵该职业 **1/2/3/4/5 人** 分别解锁 **Lv1~5**，最高 5 级。
- **两列加成**（数值均在 SkillConfig 表中配置，不硬编码）：
  - **连接英雄加成（LinkSelf）**：该职业每个英雄自身获得的属性，各档位固定。
  - **我方其他英雄加成（LinkTeam）**：该档位下全队（含英雄与士兵）获得的总量，随档位提升。
- **Tooltip 展示**：英雄 tooltip 的职业技能行只显示当前档（绿色高亮）与下一档（灰色）；商店卡（上阵 0 人）默认显示 1 级档。

## 四、配置说明

- **数据行**：`SkillConfig_s.cs`，Id 区间 2000011~2000165，`Type = "职业"`，每职业 5 行（Lv1~5），`Sname` 对应 `JobConfig.SkillId`。
- **加成格式**：`LinkSelf` / `LinkTeam` 字段，格式 `"attr+value,attr+value"`，如 `"armor+6,magicRes+6"`。
- **属性缩写**：atk 攻击 / ap 法强 / might 武力 / armor 护甲 / magicRes 魔抗 / maxHp 生命 / critRate 暴击 / attackRate 攻速 / soldierAtk 士兵攻% / soldierHp 士兵生命% / range 射程 / dodgeRate 闪避 / critDamageMulti 暴击伤害倍数
- **特殊规则**：
  - `soldierAtk`/`soldierHp` 仅对士兵生效（相）；
  - `range` 仅对射程 > 20 的远程单位生效（弩）；
  - `LinkTeam` 为该档位总量，不再乘以人数；
  - 策（策士）包含"碎片掉落"设计：技能施放后掉落魔法碎片，友军拾取后可回复法力或获得短期法强/加成（碎片逻辑为后续实现，当前以法强加成为主）。

### 数值设计提示

- 新职业 LinkSelf 建议 5 级固定（与现有 16 职业一致），LinkTeam 按档位线性增长（Lv1 基准，每级 +50%）。
- 参考现有分布：近战偏攻击/护甲/生命，远程偏攻速/射程，法系偏法强，辅助偏光环——建议新职业覆盖缺失维度：**闪避、暴伤、护盾、控制、召唤**。
