# 职业体系与兵种连锁（JobLink）配置文档

> 数据来源：`Assets/Resources/Scripts/Configs/JobConfig_s.cs`、`SkillConfig_s.cs`（职业 2000011~2000185，好友特殊连锁 2010001~2010080）
> 生效逻辑：`Assets/Resources/Scripts/Combat/JobLinkManager.cs`（兵种连锁）、`Combat/FriendLineManager.cs`（好友特殊连锁）
> 更新日期：2026-09-14（按 SkillConfig 现值全量校对，技能按类型分类）

## 一、机制总览

- **兵种连锁（JobLink）**：金铲铲式职业羁绊。战斗开始时统计本侧同职业上阵英雄数，按档位施加被动属性加成。**技能等级 = 同职业上阵人数**（1/2/3/4/5 人 → Lv1~5，`CombatConst.JobLinkBaseLevel`）。
- **好友特殊连锁（连接技能）**：`HeroFriendConfig` 中配置了 `SkillId`（关联技能缩写）的关系组，在场成员数越多技能等级越高（在场 2~6 人 → Lv1~5）；特殊连锁不加攻击属性、按配置颜色拉线。
- **两列加成**（数值均在 SkillConfig 表中配置，不硬编码）：
  - **连接英雄加成（LinkSelf）**：该职业每个英雄自身获得的属性。
  - **我方其他英雄加成（LinkTeam）**：该档位下全队（含英雄与士兵）获得的总量，随档位提升。
- **Tooltip 展示**：英雄 tooltip 的职业技能行只显示当前档（绿色高亮）与下一档（灰色）；商店卡（上阵 0 人）默认显示 1 级档。

## 二、技能类型分类

> 类型划分：攻击强化 / 魔法伤害 / 防御生存 / 控制减益 / 辅助 / 召唤。兵种技能（职业）与连接技能（好友特殊连锁）分别归类如下。

| 类型 | 兵种技能（职业） | 连接技能（好友特殊连锁） |
|------|------------------|--------------------------|
| 攻击强化 | 弓、弩、车、炮、戟、锤 | 突、连、破、穿、双、冷 |
| 魔法伤害 | 棋 | 火、偷 |
| 防御生存 | 士、盾、马、王 | 坚、镜、刺 |
| 控制减益 | 枪 | 谋、冲 |
| 辅助 | 扇、琴、医、鼓、相 | 护、背、仁 |
| 召唤 | 工 | — |

> 分类依据：按技能加成/机制归属（属性成长、伤害类型、减益/控制、生存、治疗/光环、召唤物）划分，详见第三、五节各技能明细。

## 六、配置说明

- **数据行**：职业技能 `SkillConfig_s.cs` Id 区间 2000011~2000185，`Type = "职业"`，每职业 5 行（Lv1~5），`Sname` 对应 `JobConfig.SkillId`；好友特殊连锁 Id 区间 2010001~2010080，`Type = "连接"`，`Sname` 对应 `HeroFriendConfig.SkillId`。
- **加成格式**：`LinkSelf` / `LinkTeam` 字段，格式 `"attr+value,attr+value"`，如 `"armor+6,magicRes+6"`；比例属性直接配小数（0.1=+10%）。
- **属性缩写**：atk 攻击 / ap 法强 / armor 护甲 / magicRes 魔抗 / maxHp 生命 / critRate 暴击率 / attackSpeedRate 攻速比例 / dodgeRate 闪避率 / soldierAtk 士兵攻% / soldierHp 士兵生命% / auroEffectRate 光环效果 / healRate 治疗加成 / mpRegen 法力回复 / hpRegen 生命回复
- **特殊规则**：
  - `soldierAtk`/`soldierHp` 仅对士兵生效（相）；士兵加成在 `JobLinkManager.ApplyJobLinks` 末尾统一折算进 atk/maxHp 并复位系数；
  - `LinkTeam` 为该档位总量，不再乘以人数；
  - 扇/琴的 buff 时长延长由技能事件实现（`ModifyBuffTime` + `Strength`），不走 LinkSelf 属性列；
  - 枪（晕眩）复用 `HitBuff`（BuffId=“乱”），戟/炮（溅射）复用 `HitArea`（Rate 几率 + Area 范围 + SkillDamageRate 伤害比）；
  - 破盾的穿透伤害带 `HurtTag=AntiShield`，护盾不吸收该伤害；
  - 弩的攻速为乘区比例（`attackSpeedRate`），原“射程提升”方案已废弃。
