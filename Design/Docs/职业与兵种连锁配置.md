## 一、机制总览

- **兵种连锁（职业）**：上阵同职业英雄 1 / 2 / 3 / 4 / 5 人，对应职业技能 Lv1~Lv5（`JobLinkManager`）。
- **LinkSelf**：只给"连接英雄自己"；**LinkTeam**：给我方其他英雄（不含连接英雄本人），配置数值即总量，不乘人数。
- **国家护盾**：同阵营英雄 2 / 3 / 4 / 5 / 6 人，对应 `国` 技能 Lv1~Lv5；护盾 = 最大生命 × `Strength2[shield]`，护盾 Buff 为 `300001 盾`。阵营 10（野）不参与护盾。
- **好友连锁**：见 [好友羁绊与武将分组](./好友羁绊与武将分组.md)；好友技能与职业技能同表配置，靠 `Sname` 区分。
- 数值全部走 `SkillConfig`（职业技能 Id 段 `2000001`~`2000195`），代码内只保留档位常量，不硬编码数值。
