## 二、国家连锁（已实现）

> 实现：`Combat/FactionShieldManager.cs`（`ApplyFactionShields`，战斗开始时结算）

### 1. 触发与效果
- 统计本侧场上**同阵营（HeroConfig.Side）**英雄数量。
- 达到档位后，该阵营所有英雄按**最大生命值百分比**获得护盾，持续整场战斗（`FactionShieldTime = 999`）。

| 同阵营英雄数 | 护盾（% 最大生命） |
| --- | --- |
| ≥ 3 | 18% |
| ≥ 5 | 24% |
| ≥ 7 | 30% |
| ≥ 9 | 36% |

### 2. 君主强化
- 主公技（王/帅，技能 id `200001`，职业 `shuai`）：所在阵营存在携带主公技的英雄时，**该阵营护盾效果加倍**（`MasterShieldDouble = 2`）。
- 护盾走 `BuffManager.AddShield`（BuffId `300001` 护盾），不吃减伤、独立结算。

### 3. 配置位置
- 档位 / 倍率 / 时长：`CombatConst.FactionShieldCounts / FactionShieldRates / FactionShieldTime / MasterShieldSkillId / MasterShieldDouble`
- 主公技属于职业默认技能（`JobConfig` 中 `shuai` 的 `SkillId = 200001`，由 `ConfigManager.PostModify` 注入每个 `shuai` 英雄）。

## 三、好友连锁

> 好友关系配置：`HeroFriendConfig`（目前 108 组，如「桃源结义」「五虎上将」，Level 支援级别 1~3，最多 5 人）。
> 查询接口：`ConfigManager.GetFriendLevel(heroId, friendId)`（双向配对，返回支援级别，无关系返回 0）。

### 1. 普通：连线 + 属性（已实现）

> 实现：`Combat/FriendLineManager.cs`（`ApplyFriendLines`，战斗开始时结算）

- 每个英雄统计场上与其有好友关系的其他英雄数量。
- 按档位获得**攻击强化**，并生成连线特效（`Prefabs/LaserLine`，`GlowBeamController`）。

| 连线好友数 | 攻击强化 |
| --- | --- |
| ≥ 2 | +5% |
| ≥ 3 | +10% |
| ≥ 4 | +15% |
| ≥ 5 | +20% |
| ≥ 6 | +25% |
| ≥ 7 | +30% |

- 配置位置：`CombatConst.FriendLineCounts / FriendLineAtkRates`；战斗属性在 `Chess.ApplyFriendAtkBonus / RefreshHeroAttr` 中生效，好友死亡时实时重算（`Chess.OnFriendDie`）。

### 2. 特殊：关联技能（TODO）

- 规则：特定好友关系在场时，**关联（助益）技能被激活**；好友数量越多，该技能**等级越高**。
- 与普通（攻击强化）叠加，独立结算。
- 现有可复用能力：`ConfigManager.GetShowHelpSkillId`（按站位/关系找助益技能）、`HeroConfig.Skill1/Skill2`、`SkillConfig.UnitHelpType`（同排/同列触发）。
- 设计要点（待定）：
  - 特殊好友关系如何标记（新增配置列，如 `HeroFriendConfig` 增加技能 id / 阈值字段，或新增关系类型）。
  - 技能等级提升方式：1 名好友 = 技能 Lv1，每多 1 名好友 +1 级，上限（如 Lv3）与数值待策划定。
  - 触发时机：战斗开始时与普通连锁一并结算。

| ≥ 2 | Lv2（技能数值 ×1.5） |

## 五、玩家等级体系（参考金铲铲，TODO）

> 当前现状：无玩家等级；上阵格子固定 6 个（`PlayerInfo.battleCards = new int[6]`）；商店按回合数（`ShopConfig` 按 year）配品质概率刷牌，买卡后卡位不刷新。

### 1. 等级与商店牌范围
- 规则：玩家有等级概念，**等级越高，商店可买的牌（品质/费用）范围越多**。
- 参考金铲铲：玩家等级越高，商店刷出高费/高品质棋子的概率越高；低等级只能刷出低品质牌。
- 改造点（对应当前实现）：
  - `ShopConfig.Quality2Rate / Quality3Rate / Quality4Rate`（品质 1 自动 = 100 - 其余）目前按 year 配置 → 改为**按玩家等级**配置（或等级 × 回合双维度）。
  - `HeroSelectionTool.RollQuality / GetRandomHeroIdByQuality` 的输入由 `ShopConfig(year)` 改为 `ShopConfig(玩家等级)`。
- 配置建议：新增 `PlayerLevelConfig`（或复用 `ShopConfig`）按等级 1~9 配品质概率。

### 2. 买完立刻刷新卡
- 规则：玩家购买某张卡后，**该卡位立即刷新为一张新卡**（参考金铲铲：买棋子后格子立即补充）。
- 改造点：`CardShopManager.OnPlayerBuyCard → CardViewControl.OnSold` 后，若该卡位已售出，立即用当前玩家等级重新刷一张同类卡（英雄位刷英雄、道具位刷道具）。

### 3. 上阵格子（最多 9 格）
- 规则：玩家**最多 9 个格子**，**等级越高解锁越多**（参考金铲铲人口上限随等级提升）。
- 改造点：
  - `PlayerInfo.battleCards` 由 `int[6]` 扩展为 `int[9]`（含存档兼容）。
  - 新增玩家等级字段（`level / exp`，经验来源待定：回合经验 / 胜利经验 / 购买卡牌）。
  - 上阵校验：`SetBattlePos / AutoSetBattleCard / GetStrong6CardList` 等按当前等级限制可上阵数量。
  - UI：`BagControl / MySelectControl / BattleResult` 等格子展示随等级解锁。

### 等级配置建议（参考金铲铲 1~9 级）

| 玩家等级 | 上阵格子数 | 解锁的商店牌范围（品质示例） |
| --- | --- | --- |
| 1 | 1 | 品质 1 |
| 2 | 2 | 品质 1 |
| 3 | 3 | 品质 1~2 |
| 4 | 4 | 品质 1~2 |
| 5 | 5 | 品质 1~3 |
| 6 | 6 | 品质 1~3 |
| 7 | 7 | 品质 1~4 |
| 8 | 8 | 品质 1~4 |
| 9 | 9 | 品质 1~4（高品概率最高） |

> 以上为占位示例，具体经验曲线、品质概率、格子解锁等级由策划定。

## 七、验证点
1. 3/5/7/9 同阵营英雄分别获得 18%/24%/30%/36% 护盾；帅在场翻倍。
2. 2~7 名好友连线获得 5%~30% 攻击加成，连线特效正常，好友阵亡实时重算。
3. 特殊好友关系在场时关联技能按好友数量升级。
4. 2/4 名同兵种英雄时兵种技能等级 / 数值正确提升。
5. 玩家升到对应等级后：上阵格子解锁、商店出现更高品质卡、买卡立即刷新卡位。
