# 战斗模拟器（Tools 下独立 C# 工程）

## Context

游戏战斗逻辑（`Assets/Resources/Scripts/Combat/`、`Configs/`、`PO/`、`Tools/`）几乎全是纯 C#，但深度依赖 UnityEngine 的类型与组件模型（MonoBehaviour、Vector3/Mathf/Time、GameObject/Transform、协程、Renderer/Material、Resources/JsonUtility 等），且通过 `WorldManager.Instance` / `GameManager.Instance` / `PlayerInfo` 与 Unity 场景和 UI 层耦合。

目标：在 `Tools/` 下新建独立 .NET 工程「战斗模拟器」，**直接编译游戏源码**，用一个手写 UnityEngine 桩库 + 无头 Harness 替代引擎与场景类，跑真实战斗；用 GDI+（WinForms + System.Drawing）绘制战斗画面，不做技能特效。

关键已确认事实：

* 配置数据全部硬编码在 `XxxConfig_s.cs` 的 `Load()` 中（`new HeroConfig(...)` 行），无外部数据文件 → 直接编译配置类即完成"加载游戏数据"。

* 战斗代码对外部类型的依赖收敛为：`WorldManager.Instance`（\~30 个方法）、`GameManager.Instance`（players/GetPlayer/year/PlaySound/friendRdData）、`PlayerInfo`（cards/imgPath/battleSide/GetBattleCardList/GetItemIdsOnHero/GetItemPAttr/GetSoldierHpAdd/GetSoldierAtkAdd/attrAddons 等）、`HeroInfo`（SetHpRate/SetAttr）、`ChessHUD`（仅 CreateHUD 使用，可空实现）、`PlayerBook`。

* 本机无 dotnet CLI，但 `C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe` 可用；现有 Tools（DesignCoder/Excel2dll）均为 **.NET Framework4.6.2** WinForms 工程 → 模拟器沿用该目标框架与构建方式。

* 用户确认：阵容由界面手输 heroId + 随机按钮；第一版只做 2 玩家对战（side=1 vs side=2，IsEnemy=任意不同 side 即敌，对应 TeamMode 2 语义）。

## 方案：编译游戏源码 + UnityEngine 桩 + 无头 Harness

游戏源码**零修改**（保持单一数据源），通过 MSBuild `<Compile Include=... Link=...>` 链接进模拟器程序集；桩库在**同一程序集**内定义 `namespace UnityEngine`（含 `UnityEngine.UI`/`EventSystems` 空命名空间占位，因 `using` 未引用类型不会报错）。

## 实施步骤

1. **工程骨架**：手写 sln/csproj（参照 [DesignCoder.csproj](file:///d:/Codes/SanTeam2/Tools/DesignCoder/DesignCoder/DesignCoder.csproj) 的目标框架与引用风格）。游戏源码用通配符链接：
   `<Compile Include="..\..\..\Assets\Resources\Scripts\Combat\**\*.cs" Link="Game\Combat\%(RecursiveDir)%(Filename)%(Extension)" />`（Configs/PO/Tools 同理）。**不改动** Unity 侧任何文件，不新增 `.meta`，不动 Assembly-CSharp.csproj（Tools 不在 Assets 下，Unity 不参与编译）。

2. **UnityEngine 桩**：按上文文件清单实现。要点：

   * `MonoBehaviour` 携带 `Transform` 与协程运行时；桩的**组件工厂**（`GameObject.AddComponent`/`GetComponent<T>` 创建实例后）用反射把类型为 Renderer/Material 等的公开字段（如 Chess.rend/rendFlag）注入桩实例，避免空引用（游戏里这些是预制体序列化字段）。

   * `Instantiate(prefab,...)` 返回哑对象；`Resources.Load<GameObject>("Prefabs/Hud"/"HudSmall")` 返回带 `ChessHUD` 组件的哑预制体，其余返回 null（null prefab 时 Instantiate 仍返回可用哑对象，避免 CreateHUD/导弹特效空引用）。

   * `WaitForSeconds` 由 `CoroutineRunner.Step()` 按 `Time.time` 推进；`Time.time` 由模拟器主循环累加（`Time.deltaTime` 同步）。

3. **Harness**：

   * `WorldManager` 复刻原版被战斗层用到的全部成员（签名见 [WorldManager.cs](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs)）：
     `SpawnUnitsForRegion`（按 [L447-491](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs#L447-L491) 逐字段赋值 + `Init`）、`OnUnitDying`（[L1171](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs#L1171-L1358) 的 TeamMode2 语义，2 侧简化版）、`GetRange/CheckInRange`（按 [L1360-1374](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs#L1360-L1374) 的 gridCellSize 网格距离）、`GetUnitsInRange/GetUnitsMySide/GetAllEnemys/GetUnitsInRangeByTag/RandomSelect/FindByHeroIdAndSide/IsEnemy`（TeamMode2：`a != b`）、`CreateAttackMissile/CreateSpellMissile`（创建 Missile 实例并启动对应协程）、`AddBattleText`（收集到列表供 GDI+ 飘字）、`CheckPositionBlocked`（无墙→false）、`FindMoveWaypoint`（无墙→null）、`TryLockGridPositions`（无墙→true）、`MoveTo`、`WorldToGridPosition`、`GetOccupiedGrids`（Collider 桩给默认 bounds）、`HudNode/Units`（哑 GameObject）。墙/地图初始为空（模拟器不加载地图，单位直接用布阵坐标）。

   * `GameManager`：`players` 数组按模拟器设置填充（pid 0/1 或按 PlayerConfig），`GetPlayer` 越界记录日志返回 null，`PlaySound` 空实现，`friendRdData` 空列表（`ConfigManager.InitFriend` 不会被战斗流程调用）。

   * `PlayerInfo`：字段与上文清单一致；`GetBattleCardList()` 由 `battleCards`（25 格数组）转 `List<Tuple<int,int>>`（heroId, lv=GetCardLevel(cards\[heroId], true)），复刻原版语义；`GetItemIdsOnHero`/`GetItemPAttr` 遍历 `items`（v1 模拟器不填装备，返回空/0）；`GetSoldierHpAdd/GetSoldierAtkAdd` 按 SoldierLevelConfig 累加（同原版 L1165-1173 逻辑）。

4. **战斗驱动** **`BattleSim.cs`**（模拟器自带，不在 Harness 里但属于桥接核心）：

   * `InitBattle(team1Heroes, team2Heroes, seed)`：`SysRandom.Seed(seed)` → `ConfigManager.Init()` → 构造 2 个 PlayerInfo（各自 battleCards：前排 5 个小兵 + 3\~5 个英雄布阵到 HeroCells 与剩余格）→ 复刻 `SpawnUnitsInRegions` 的两侧生成（参照 [WorldManager L219-317](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs#L219-L317) 的 debug/PVP 简化版：`SpawnSoldiersForSide` + `SpawnHerosForSide`，center 换成模拟器 5x5 网格原点，`GetFormationCellPos` 按 FormationCellSize 计算）。

   * 复刻 [BattleBegin L111-141](file:///d:/Codes/SanTeam2/Assets/Resources/Scripts/WorldManager.cs#L111-L141) 的后处理顺序：`JobLinkManager.ApplyJobLinks()` → `FriendLineManager.ApplyFriendLines()` → `ApplyFriendSpecialSkills()` → `FactionShieldManager.ApplyFactionShields()` → 逐个 `SkillManager.BattleBegin(chess)`。

   * 主循环 `Tick(dt)`：`Time` 累加 → 推进 `CoroutineRunner` → 所有存活 `chess.LogicUpdate(dt)` → 推进 Missile 列表（协程已涵盖）→ 检查 `gameFinish`（一方存活单位数为 0）。

   * 输出：胜负、`BattleStatManager.GetTop10()` 伤害统计、战斗时长。

5. **GDI+ 主窗体**：`Timer`（按速度倍率调 `Tick`）+ `OnPaint` 绘制——两侧背景色、单位圆（英雄大、小兵小，按 side 着色）、HP 条、`AddBattleText` 收集的飘字（限时淡出）。控制区：seed 输入、两侧 heroId 输入框、随机阵容、开始/暂停/重置、速度 1x/2x/4x、战斗日志（GameLog 输出重定向到窗口）。

6. **构建与验证**：

   * `MSBuild.exe BattleSimulator.csproj /p:Configuration=Debug`（用 `C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe`）。

   * 验证链路：`--headless --seed 1 "101001,101002,101003" "102001,102002,102003"` 跑一场 → 断言双方生成数量、战斗结束、胜负/伤害统计输出非空；再换不同阵容/seed 跑多场，确认无异常退出。

   * 迭代方式：先保证 headless 编译+跑通，再逐步补 GDI+ 绘制；编译报错时按"缺什么桩补什么桩"的方式增量补齐 UnityEngine 成员。

## 不做的事（明确排除）

* 不改任何游戏源码、不加 .meta、不动 Unity 的 csproj。

* 不做技能特效/动画/音效/地图碰撞/墙寻路（墙集合为空，移动逻辑保留）。

## 依赖面调研结论（Harness 实现蓝本，2026-09 已核对源码）

### WorldManager 对外 API（Harness 需精确复刻签名）

- `static WorldManager Instance; int gridCellSize=3; GameObject HudNode; int idCounter`
- `Chess SpawnUnitsForRegion(PlayerInfo p, int soldierId, int posId, Vector3 spawnPos, int side, string imgPath)` — 从 SoldierConfig 取值逐字段赋值后 `chessComponent.Init(p.pid, posId, p.lineColor)`，`chessList.Add`，`idCounter++`。p 不可为 null。
- `bool IsEnemy(int a,int b)` — TeamMode2 即 `a != b`（1v1 直接对等，side=1 vs 2）
- `void OnUnitDying(Chess dieUnit, int killerPlayerId)` — `chessList.Remove`；统计存活 side（排除 isShadow），`aliveSideCount==1` 时 `gameFinish=true; hasWin=存活阵营==1`
- `bool CheckInRange(Vector3 p1, Vector3 p2, float range)` / `float GetRange(...)` — 基于 `WorldToGridPosition(pos,true)` 的 `Vector2Int.Distance`（格子中心距离，单位=米）
- `Vector2Int WorldToGridPosition(Vector3 pos, bool floor)` — `FloorToInt(x/3)*3` / `CeilToInt(...)*3`
- `List<Chess> GetUnitsInRange(Vector3 wPos, float range, int mySide, bool findEnemy)` — range==0 全图；`IsEnemy(side,mySide)` 过滤；排除 hp<=0/isShadow
- `List<Chess> GetAllEnemys(int mySide)` — 仅英雄，优先配对 `(mySide+1)/2==(c.side+1)/2`
- `List<Chess> GetUnitsInRangeByTag(Vector3,float,string summonTag)`
- `void RandomSelect(List<Chess>, int limit)` — 注意游戏里用的是 `new System.Random()`，桩可换 SysRandom
- `List<Chess> GetUnitsMySide(int mySide)` / `GetUnitsMySide(Vector3,float,int)`
- `Chess FindByHeroIdAndSide(int heroId,int side)` — 英雄存活
- `void CreateAttackMissile(Chess src, Chess tgt, string effectName)` — 创建 Missile + `MoveToTarget`；CreateSpellMissile 两个重载
- `bool MoveTo(Chess unit, Vector3 pos, bool isForce=false)` — `unit.transform.position = pos; return true`
- `Vector3? FindMoveWaypoint(Vector3 from, Vector3 to)` — 无墙时直线通畅返回 null（可简化为 null）
- `bool CheckPositionBlocked(Chess unit, Vector3 pos)` — 无墙返回 false
- `bool TryLockGridPositions(Chess, Vector3, out List<Vector2Int>)` — 无墙返回 true
- `void AddBattleText(string text, Vector3 worldPos, Vector2 speed, Color color, int duration)` — 桩可空（或记录日志）
- `Vector2 TransformWorldToScreen(Vector3, RectTransform)` — 桩返回零向量
- `bool IsPathBlockedGrid(Vector2Int)` — 无墙返回 false
- `BattleBegin()` 流程（世界复刻）：`SpawnUnitsInRegions`(置 battleSide=1/2、按布阵生成士兵+英雄) → `JobLinkManager.ApplyJobLinks()` → `FriendLineManager.ApplyFriendLines()` → `ApplyFriendSpecialSkills()` → `FactionShieldManager.ApplyFactionShields()` → 遍历 chessList `SkillManager.BattleBegin(chess)` → 每 0.05s 遍历存活 chess `LogicUpdate(0.05f)` 直至一方全灭
- 布阵坐标：`GetFormationCellPos(center,pos)`：row=pos/5,col=pos%5，`center + forward*(row-2)*CellSize + right*(col-2)*CellSize`；模拟器简化：side1 中心 (0,0,-30)、side2 (0,0,30)、forward=Vector3.forward、right=Vector3.right、CellSize=13、GridSize=5。士兵 battleCards 中 500001/500002 生成；英雄按 GetBattleCardList。

### GameManager 接口

- `static GameManager Instance; PlayerInfo[] players; List<FriendRandomData> friendRdData; int year;`
- `PlayerInfo GetPlayer(int pid)`；`void PlaySound(string path,int priority=3)` 桩空实现
- `FriendRandomData` 为嵌套类：`{int id; string name; int[] friendIds;}`（[Serializable]）

### PlayerInfo 字段/方法（Harness 精简版）

- 字段：`pid, playerId, playerConfig, isAI, cards(Dictionary<int,int>), items(List<SerializableItemSlot>), battleCards(int[]), attrAddons(Dictionary<int,AttrInfo>), battleSide, lineColor(Color), banCount, sodatk, sodhp, soldierLevel, level, exp, lastBattleLose, mark, gold, castleHUD`
- `imgPath => "Textures/" + playerConfig.Imgpath`；`playerName => playerConfig.Name`
- `List<Tuple<int,int>> GetBattleCardList(bool isTest=false)` — 非AI且 battleCards 有英雄时按 battleCards 返回长度25列表 `(heroId, GetCardLevel(cards[heroId],true))`；否则用 GetStrongCardList+RearrangePos（Harness 可只实现 battleCards 分支，isAI=false 手输阵容走此分支）
- `List<int> GetItemIdsOnHero(int heroId)` — items 中 HeroId==heroId 的 ItemId
- `int GetItemPAttr(string attrName)` — GetItemList("pattr") 的 Attrs 解析求和（用 JobLinkManager.ParseBonuses）
- `int GetSoldierAtkAdd()/GetSoldierHpAdd()` — Harness 可返回 sodatk/sodhp 或 0
- `void onBattleResult(bool isWin,int add)` — Harness 记录胜负即可
- `void OnBattleBegin(){}`；`void AddItemCard(int)` — items 加槽位
- `bool GetSlotCount()` 返回格子数（GetBattleCardList 用）；`void AutoSetBattleCard()` 等 UI 相关可不实现（未编译则不要求）
- `SerializableItemSlot`：`{int ItemId; int HeroId;}`

### 其它关键点

- `ConfigManager.Init()` **不**访问 GameManager.Instance（friendRdData 只在 InitFriend 中，战斗不调用）→ Harness 可先 Init 后设置 GameManager.Instance
- `Chess.Init` 中 `playerInfo.cards.TryGetValue(heroId, out heroExp)` → playerInfo 可 null（怪物）；`HeroSelectionTool.GetCardLevel(exp,true)` 卡片等级
- `Chess.CheckInitAttr(player, lv)`：maxHp/moveSpeed/attackRange/attackSpeed(AtkSpeed/30)/ap/atk/armor/magicRes/hpRegen/mpRegen 取自 HeroConfig+GetCardAttr(player,heroId,lv)；装备 GetItemIdsOnHero + GetCardAttr(player,equipId,1)；`heroInfo?.SetAttr(ap,atk)`
- `Chess.Init` 技能创建：`SkillManager.CreateSkill(skillCfg.Id, this)` 按 `ScriptName` switch；`skills` 集合；`AddSkill(skillId,parentSkillId,level)` 去重
- `HeroInfo` 需 `SetHpRate(int,int)` / `SetAttr(int,int)`（Chess.heroInfo 非 null 即调用）；`ChessHUD` 需 `chessUnit` 字段 + `UpdateHealthDisplay()`
- `Chess` 公开字段（桩工厂反射注入）：`rend/rendFlag`(Renderer)、`material/materialFlag`(Material)
- `Skill` 基类：`id, owner, skillCfg, Level, mp, skillId`；`GetSkillDamage()/GetSkillHeal()/SetLevel(lv)/UpdateCD()/IsInCD()/CheckBurst(target)/BattleBegin()/SummonUnit(pos,soldierId,imgPath)/SummonMagicField(pos,out summonTime)`
- `Buff` 基类：`id, caster, owner, buffCfg, skillCfg, endTime, effect`；`OnAdd/OnRemove/Refresh/SetTime/WaitForRemove/BeforeCalDamage/BeforeCalDamaged/DuringCalDamage`
- `BuffTime`：`{int id; float time;}`；`AttrInfo`：Ap/Atk/Hp/Armor/MagicRes/AttackSpeedRate/CritRate/MpRegen/HpRegen + AddAttr
- `GameLog`：使用 `UnityEngine.Application.persistentDataPath` 与 `logMessageReceived` → 桩需提供；日志写文件 OK
- 战斗统计：`BattleStatManager.AddBattleStat(playerId, heroId, damage, isHero, targetIsHero)` 静态 + `GetTop10()` + `Clear()`
- `CombatConst`：FormationGridSize=5、FormationCellCount=25、PlayerMaxSlot、SoldierMagicField(501001)、FactionShieldCounts/FactionShieldSkillSname、FriendLineCounts/FriendLineSkillSname、FriendSpecialBaseLevel、DamageTypeMagic/Attack/Real、ResistMultiplier(armor)=100/(100+armor)、MoveReplanInterval、MoveSeparationDist/Force/AllyForce、MoveLaneBias、MovePathMaxDepth、InitAddItemLoseRateBonus

## 验证方式

1. `MSBuild` 构建成功（无编译错误）。
2. `--headless` 模式跑通一场完整战斗并打印：双方上阵数、结束原因（胜负）、BattleStat 前 10、耗时；多 seed 抽样无崩溃。
3. WinForms 窗口打开后：随机阵容 → 开始 → GDI+ 画面推进、单位移动/掉血、一方团灭后弹结果，速度切换/暂停/重置正常。
